Run Claude Code on 20+ models.

A local proxy at localhost:8080 that speaks the Anthropic Messages API, so Claude Code can use Gemini, GPT, Grok, Claude, Kimi and Perplexity search models, with managed sessions, automatic failover, a live dashboard and a status bar in your IDE.

How it works

Claude Code CLI / extension→Antigravity proxy · localhost:8080→Google AI (Gemini) · Perplexity · more

Features

Multi-provider

Gemini, GPT, Grok, Claude, Kimi and more through one Anthropic-compatible endpoint.

Session failover

Keeps requests on a stable signed-in session and moves to another when one is unavailable.

Live dashboard

Accounts, usage and one-click model switching at localhost:8080/dashboard.

IDE status bar

Current model and quotas with reset times, right in VS Code or Antigravity.

Agentic fallback

Chat-only models switch to an agentic model automatically when tools are needed.

Offline test suite

Lint and tests run in CI on Node 20 and 22 with no accounts, keys or network.

Quick start

git clone https://github.com/muhib-karim/Antigravity-Claude-Code-Proxy.git
cd Antigravity-Claude-Code-Proxy/Antigravity-Claude-Code-Proxy
npm install
export GOOGLE_OAUTH_CLIENT_SECRET="<your OAuth client secret>"
npm run accounts:add          # Google sign-in in your browser
npm start                     # proxy on http://localhost:8080

export ANTHROPIC_BASE_URL="http://localhost:8080"
export ANTHROPIC_API_KEY="antigravity-proxy"
claude                        # Claude Code now goes through the proxy
